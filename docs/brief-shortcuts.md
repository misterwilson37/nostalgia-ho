## Shift + the letter alone

No browser or system takes Shift + a letter or a digit: every key above would work, End Turn (Shift+T) included, in every browser. The only
care: not while the focus is in a text field (Send Message's text, Name a Star, the New Game form), where Shift+T is a capital T. The
skin's menus would show "⇧T" (Mac) / "Shift+T" (Windows) beside each item, in place of the original key, so the menus stay honest; with
modern conveniences off as well as on, since the keys are the originals' own.

Recommendation: Shift + the letter for every version, the originals' letters as above; also take ⌘⇧ / Ctrl+Shift where it is free
(✓ above) for people whose fingers remember the chord.
