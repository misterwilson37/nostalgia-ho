# The browser OS looks

Spaceward Ho! has looks for every system the game was released on, and now
for the one the remake runs on: the web. Five new OS looks, in every skin:

- **Netscape Navigator 3 (Windows)**, 1996: Windows 95's windows and controls,
  as Navigator used them, with Navigator's own pieces: the menus as raised
  toolbar buttons, a sunken "Location:" field showing your game, the throbber
  box at the right, and the status bar reading "Document: Done". While the
  title screen loads, the throbber's moon circles its planet and the status
  line says it's contacting spacewardho.com.
- **Netscape Navigator 3 (Mac)**: the same, on Mac OS 8's Platinum windows,
  with the menus left in the Mac's menu bar.
- **Firefox**, **Edge** and **Safari**, as each browser draws itself in 2026.
  Each follows your system's light or dark setting.

Pick one from the **OS look** menu (New Game, the title screen, or the Ho
menu's **Skin and OS look…**), or add `?os=netscape`, `netscapemac`,
`firefox`, `edge` or `safari` to the address. The Windows 95 skin offers the
Windows Netscape among its own looks, the Mac 4.0.5 skins the Mac one, and
Cozy and Gemini the three modern browsers.

The looks use your computer's own fonts (so Safari's shows San Francisco on a
Mac, and Edge's Segoe UI on Windows) and draw everything in CSS. No browser's
logo appears anywhere; the throbber's ringed planet is the remake's own.

`preview-light.png` and `preview-dark.png` show each look's New Game window
and its game screen with a menu open.
