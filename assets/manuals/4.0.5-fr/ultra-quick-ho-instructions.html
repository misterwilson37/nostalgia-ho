Pour commencer

Instructions ultra-rapides pour le Ho!

Voici le résumé en un paragraphe de ce que vous devez savoir. Installez Spaceward Ho! 4.0 sur votre disque dur. Jouez avec les barres pour ajuster les dépenses. Cliquez sur les messages de la carte pour les faire disparaître. Double-cliquez sur une colonie pour concevoir et construire des vaisseaux. Faites glisser d’une étoile à l’autre pour déplacer les vaisseaux. Expérimentez. Conquérez la galaxie.
