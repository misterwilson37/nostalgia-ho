Régler la vitesse des batailles

Vous pouvez régler ici la vitesse des tirs et des explosions dans les revues de bataille. Si vous vous ennuyez à regarder les batailles, accélérez-les. Cocher Les groupes tirent ensemble accélère considérablement les batailles, surtout les très grandes. Décocher Animation complète supprime les images d’explosion, ce qui rend les batailles encore plus rapides.
