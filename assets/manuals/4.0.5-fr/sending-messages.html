Les autres joueurs

Envoyer des messages

Vous pouvez envoyer des messages aux autres joueurs d’une partie de Spaceward Ho!. Comme les joueurs ordinateur doivent comprendre et envoyer leurs propres messages, un langage simple a été conçu pour tout le monde dans la partie.

Pour envoyer un message, choisissez simplement Envoyer un message dans le menu “Galaxie”. Une boîte de dialogue s’ouvre et vous permet de décider à qui envoyer, quoi dire, et ainsi de suite. Le meilleur moyen d’apprendre tous les messages est de les essayer tous.

Les messages auront des effets variables sur la personne qui les reçoit. Si vous dites à un joueur que vous le détestez, il aura tendance à moins vous apprécier qu’avant. Si vous dites que vous l’aimez bien, il vous aimera peut-être en retour, ou peut-être pas.

Les joueurs ordinateur mentent parfois dans leurs messages, certains plus que d’autres. Mais ils ne peuvent pas mentir sur certains messages, tout comme vous.

Vous pouvez envoyer des messages privés à d’autres joueurs, mais il faut un tour pour que le message arrive, comme pour les autres messages.

Dans les parties en réseau, vous pouvez discuter en temps réel avec les autres joueurs dans la fenêtre de discussion. Tapez simplement vos messages et les autres joueurs verront instantanément vos commentaires dans leur fenêtre de discussion.

Aide de Spaceward Ho! 4.0.5 — convertie à partir du fichier WinHelp.
