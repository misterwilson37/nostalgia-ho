Le menu Options

Afficher les messages d’événements

Si cet élément est sélectionné, tous les messages d’événements s’affichent dans le coin inférieur gauche de la carte au début de chaque tour. Cliquez sur le message ou appuyez sur Retour pour passer au suivant.

Tous les messages apparaissent dans la fenêtre des rapports, que cet élément soit coché ou non.

Vous pouvez régler le Ho! pour qu’il ne vous donne que les messages concernant les choses « importantes » : batailles et progrès technologiques. Pour cela, choisissez Mais seulement les plus importants. C’est très pratique dans les parties à grande vitesse.
