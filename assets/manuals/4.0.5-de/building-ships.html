Schiffe

Schiffe bauen

Schiffe können Sie in jeder Ihrer Kolonien bauen. Klicken Sie dazu auf den Planeten, auf dem Sie Schiffe bauen wollen, und wählen Sie im Menü „Schiffe“ den Eintrag Schiffbau oder doppelklicken Sie einfach auf den Planeten. Ein großer Dialog erscheint. In diesem Dialog können Sie sowohl Schiffe bauen als auch neue Schiffstypen entwerfen. Sie können die Anzahl der Schiffe wählen, bevor Sie den Typ wählen, und dann ihre Technikstufen anpassen, bis Metall- und Geldkosten da liegen, wo Sie sie haben möchten.

Links im Dialog sehen Sie eine Liste der verfügbaren Schiffstypen. Wenn keiner davon Ihrem Geschmack entspricht, können Sie unten in der Mitte des Bildschirms mit den Schiebereglern eine neue Klasse entwerfen.
