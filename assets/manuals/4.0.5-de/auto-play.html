Das Menü „Optionen“

Autospiel…

Bei „Automatisch spielen“ erledigt der Computer Ihren Zug automatisch.

Wenn Sie wollen, dass der Computer für Sie spielt, wählen Sie Der Computer spielt für mich. Der Computer entwickelt eine eigene Strategie, genau wie die normalen Computergegner. Das ist für Anfänger ein guter Weg zum Lernen. Es ist auch sehr praktisch, wenn Sie kurz vor dem Sieg (oder der Niederlage) stehen, das Spiel aber nicht selbst zu Ende spielen wollen. Wählen Sie diese Option auch, wenn Sie eine Mehrspielerpartie vorzeitig verlassen müssen, Ihr Gebiet aber nicht völlig zerfallen soll.

Auch wenn der Computer für Sie spielt, behalten Sie etwas Kontrolle. Der Computer ändert nie Ihre Balken für die Technikausgaben. Wenn Sie Schiffe bauen, setzt der Computer sie ein. Wenn Sie Schiffe irgendwohin schicken, lenkt der Computer sie nicht um, bevor sie ihr Ziel erreicht haben. Der Computer versucht im Allgemeinen, die Kolonien zu behalten, die Sie haben, es sei denn, er hält sich für zu weit ausgedehnt.

Wählen Sie Mich in jedem Zug nur als fertig markieren, geschieht auch nur das. Keiner Ihrer Budgetbalken ändert sich je (außer wenn Sie Planeten verlieren oder gewinnen). Das ist eine praktische Option, wenn mehrere Züge hintereinander nichts Interessantes passiert, etwa wenn Sie darauf warten, dass eine Kolonie rentabel wird.

Wählen Sie Mich als fertig markieren, bis etwas Interessantes passiert, spielen Sie nicht, bis ein Kampf stattfindet. Dann spielen Sie weiter.

Wählen Sie Ich spiele meine Züge selbst, um das automatische Spielen auszuschalten.

Der Schieberegler unten im Dialog Autospiel… bestimmt, wie lange jede Nachricht angezeigt wird. Normalerweise müssen Sie jede Nachricht anklicken, damit sie verschwindet. Beim automatischen Spielen können Sie weiterhin klicken, aber läuft die Zeit ab, verschwindet sie von selbst. Das ist nur wichtig, wenn Sie dem Computer beim automatischen Spielen zusehen.

Den Stil des Computerspiels legen Sie fest, wenn Sie ihn auf automatisches Spielen schalten. Die Schieberegler unter Einstellen bestimmen, wie sehr Ihr Computer zum Angreifen und Verteidigen neigt. Probieren Sie die Regler aus – Sie kommen schon dahinter.
