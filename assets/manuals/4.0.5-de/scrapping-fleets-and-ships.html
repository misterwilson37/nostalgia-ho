Schiffe

Flotten und Schiffe verschrotten

Im Lauf des Spiels werden Sie feststellen, dass Metall knapp ist und Ihre veralteten Schiffe so gut wie nutzlos sind. Vielleicht möchten Sie einige Ihrer älteren Schiffe loswerden. 75 % des Metalls einer Flotte an Ihren Kolonien holen Sie zurück, indem Sie die Flotte verschrotten (wählen Sie im Menü „Schiffe“ den Eintrag Aktuelle Flotte verschrotten). Oder Sie verschrotten einen ganzen Schiffstyp (klicken Sie im Dialog Schiffe bauen/entwerfen bei einem bestimmten Typ auf Alle verschrotten).

Wenn Sie einen Schiffstyp oder eine Flotte zum Verschrotten markieren, wird sie erst verschrottet, wenn Sie den Zug beenden. Bekommen Sie bis dahin kalte Füße, können Sie einfach im Dialog Schiffe bauen/entwerfen auf die Taste Nicht verschrotten klicken oder im Menü „Schiffe“ den Eintrag Aktuelle Flotte nicht verschrotten wählen.

Wollen Sie nur einen Teil einer Flotte verschrotten, teilen Sie die Flotte im Dialog Schiffe ordnen in die Schiffe, die Sie behalten wollen, und die, die Sie verschrotten wollen.

Verschrotten Sie Schiffe, die sich über einer Kolonie befinden, geht das Metall sofort in Ihren globalen Vorrat, und Sie können es sofort verwenden. Gehört Ihnen der Planet unter den Schiffen nicht, fällt das Metall auf den Planeten. Wer ihn als Nächster kolonisiert, kann dann das Metall Ihrer verschrotteten Schiffe abbauen.
