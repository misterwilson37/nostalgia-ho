Änderungen und Ergänzungen

Spaceward Ho! – Ergänzungen von 3.0 zu 4.0

In Version 4.0 des Ho! steckt jede Menge Neues. Kennen Sie 3.0, können Sie mit der neuen Version spielen und alles selbst herausfinden. Die folgende Liste der neuen Funktionen ist aber praktisch, damit Sie wissen, was Sie bekommen.

Mehrere neue Radikaltechniken sind hinzugekommen, und die alten wurden für ein besseres Spielgleichgewicht angepasst. Drei neue Schiffstypen wurden hinzugefügt – Schlachtschiffe, Tanker und Bioschiffe. Mehrere Dialoge wurden überarbeitet, besonders der für den Schiffbau.

Sie können das Kampfglück jetzt beim Beginn eines neuen Spiels ausschalten, sodass kein Spieler im Kampf je die schwarze Katze oder das Hufeisen bekommt. Unmengen neuer Grafiken und Klänge wurden hinzugefügt. Die Schwerkraft eines Planeten erkennen Sie jetzt an seinem Bild – größere Planeten haben höhere Schwerkraft. Außerdem sehen Sie auf der Sternkarte, ob ein blauer Planet heiß oder kalt ist. Satelliten sind doppelt so schwer zu zerstören und schießen in jeder Runde zweimal. Sie kosten auch doppelt so viel Geld und Metall im Bau. „Ausgaben anpassen“ geschieht automatisch, wenn Sie Ihren Zug beenden, und steht daher nicht mehr in den Menüs.

Das Verhältnis von Abbau und Terraformen stellen Sie jetzt mit einem Schieberegler statt dem alten Kreisdiagramm ein. Das Bild des Planeten sehen Sie schon, bevor Sie ihn terraformt haben. Klicken Sie auf das Bild, um seine Einzelheiten zu sehen.

Ho! führt jetzt Statistiken darüber, wie Sie im Lauf des Spiels abgeschnitten haben, sowie darüber, wie ein Spieler über mehrere Spiele vorankommt, mit einem System aus „Meisterpunkten“. Jedes Mal, wenn Sie ein Spiel gewinnen, bekommen Sie „Meisterpunkte“ je nach Schwierigkeit des Spiels. Sammeln Sie so viele, wie Sie können; schwerere Spiele sind viel mehr Punkte wert.

Das neue System bewertet die Schwierigkeit des Spiels auf einer groben Skala von 0 bis 100. Die endgültige Schwierigkeit hängt von der Zahl der Verbündeten, dem Tempo des Spiels und so weiter ab. Sie können jetzt anderen Spielern private Nachrichten senden, aber es dauert einen Zug, bis die Nachricht ankommt, genau wie bei anderen Nachrichten.

Außerdem gibt es jetzt eine Zuguhr im Schachstil, um das Spiel zu beschleunigen. Computerspieler werden in der Symbolliste nach Einkommen aufgeführt. Auch teuflische Computerspieler sind noch schlauer geworden, nehmen Sie sich also in Acht. Sie lieben Schlachtschiffe.

Es gibt jetzt zwei Stufen von Bündnissen – normal und beste Freunde. Außerdem können spät eintretende Spieler für einen Computerspieler einspringen. Sie werden bemerken, dass in einem Netzwerkspiel die Züge viele Male schneller aktualisiert werden als früher. Auch Einzelspielerspiele aktualisieren schneller. Chatten in Echtzeit sowie frei formulierte Nachrichten für die private Kommunikation wurden hinzugefügt.

Jeden Zug erhalten Sie Tipps zum Spielen von Spaceward Ho!. Im Dialog „Einstellungen“ können Sie sie abschalten, sobald Sie glauben, alle gesehen zu haben.

Neue Ostereier – aber wir können Ihnen hier nichts darüber verraten. Sie werden sie finden oder im Netz davon hören. Software-Aktualisierungen für Spaceward Ho! (sobald sie erscheinen) finden Sie außerdem bei America Online (Stichwort: delta tao) oder per FTP unter sumex.aim.stanford.edu (oder auf einer Vielzahl anderer Server).
