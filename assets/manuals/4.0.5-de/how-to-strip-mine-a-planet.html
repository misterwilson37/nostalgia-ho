Planeten erkunden

So betreiben Sie Raubbau an einem Planeten

Manchmal geht Ihnen das Metall aus. Dann ist ein guter Zeitpunkt, einen Planeten zu kolonisieren, von dem Sie genau wissen, dass er nie Gewinn abwerfen wird, egal wie viel Sie terraformen und wie lange Sie warten. Vielleicht hat er 3,5 G oder sogar noch mehr. Kolonisieren Sie den Planeten, aber stellen Sie seine Ausgaben so ein, dass Sie kein Geld für das Terraformen ausgeben. Stecken Sie alles in den Abbau. Wenn Sie so viel Metall vom Planeten geholt haben, wie Sie wollen, „verlassen“ Sie ihn. Alle Satelliten, die Sie dort gebaut haben, bleiben, aber Ihre Kolonisten werden evakuiert.

Manchmal möchten Sie einen Planeten vielleicht nur abbauen, um zu verhindern, dass ein Feind an sein Metall kommt.
