Installing Spaceward Ho!

It's best to put Spaceward Ho! on your hard drive. You can run it from the CD if you like, but it's slower that way, and more annoying.

To install Spaceward Ho!, just drag its icon from the CD that came with this package to your hard drive.

We're usually so brief that this would be the whole explanation. Since we're trying to fluff out the manual, however, we'll cover all the potential problems you might face.

Potential Installation Problems
