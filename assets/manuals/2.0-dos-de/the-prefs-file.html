Die Prefs-Datei

Wenn Sie Spaceward Ho! zum ersten Mal starten, wird eine Einstellungsdatei namens „Spaceward Ho! Prefs“ angelegt. Haben Sie System 7.0, wird sie im Ordner „Preferences“ im Systemordner Ihres Startvolumes angelegt. Andernfalls wird sie im selben Verzeichnis wie das Programm Spaceward Ho! angelegt.

Wir speichern alles in der Einstellungsdatei: wo Sie die Fenster gern platzieren, ob der Ton ein- oder ausgeschaltet sein soll, Ihre bevorzugte Kampfgeschwindigkeit und so weiter.

Außerdem speichert die Einstellungsdatei die Namen aller Leute, mit denen Sie je gespielt haben, alle Namen der Schiffe, die Sie je entworfen haben, und alle Sterne, die Sie je nach einem gewonnenen Spiel benannt haben.

Um ganz neu anzufangen (etwa wenn Sie einmal ein Schiff nach Ihrer neuen Exfreundin benannt haben und der Anblick ihres Namens schmerzliche Erinnerungen weckt), werfen Sie einfach die Einstellungsdatei weg. Alle diese Informationen werden gelöscht.
