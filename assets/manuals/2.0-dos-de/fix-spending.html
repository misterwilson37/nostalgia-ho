Ausgaben anpassen

Den Befehl „Ausgaben anpassen“ finden Sie im Menü „Galaxie“. Er macht ein paar Dinge.

Geben Sie für einen Planeten zu wenig aus (nicht bis zur schwarzen Linie), wird gerade so viel Geld hinzugefügt, dass die schwarze Linie erreicht wird. Das Geld wird von Ihren Ersparnissen abgezogen; haben Sie keine Ersparnisse, geschieht nichts. Geben Sie für einen Planeten null Prozent aus, nimmt das Spiel an, dass Sie ihn aufgeben wollen, und passt die Ausgabenbalken nicht an.

Geben Sie für einen Planeten zu viel aus (mehr Geld, als für Terraformen, Abbau und den Bau der gerade eingereihten Schiffe nötig ist), wird der Balken des Planeten gerade so weit gesenkt, dass er bezahlt, was getan werden muss. Überschüssiges Geld geht in die Ersparnisse.

Für jeden angepassten Balken erscheint unten links in der Sternkarte eine Meldung. Werden dort noch normale Zugmeldungen angezeigt, ist die Option „Ausgaben anpassen“ grau, bis Sie alle durchgeklickt haben.
