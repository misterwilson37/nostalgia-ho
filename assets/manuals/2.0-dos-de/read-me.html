Besonderer Hinweis zum Passwortschutz

Spaceward Ho! verlangt vom Benutzer, in zufälligen Abständen während des Spiels ein Passwort einzugeben. Die Passwörter liegen Ihnen zur Bequemlichkeit auf einem separaten Beiblatt bei.

Spaceward Ho! – Aktualisierte Informationen

Wichtige Informationen zu Spaceward Ho! für Windows. Diese Datei enthält Informationen, die möglicherweise nicht in Ihrem Handbuch stehen. Bitte nehmen Sie sich einen Moment Zeit, diese Informationen zu lesen. Dieser Text lässt sich vielleicht leichter lesen, wenn Sie das Notepad-Fenster auf die maximale Größe vergrößern. Klicken Sie dazu auf die Schaltfläche „Maximieren“ in der oberen rechten Ecke oder drücken Sie ALT+LEERTASTE und dann X. Hilfe zur Verwendung von Notepad erhalten Sie mit F1.

256 Farben, 16 Farben oder Schwarzweiß

Spaceward Ho! unterstützt die Modi Schwarzweiß (Monochrom), 16 Farben und 256 Farben. Bei der Installation von Windows wird normalerweise ein allgemeiner 16-Farben-Treiber installiert. Jeder Hersteller von Grafikkarten liefert eine Diskette mit Treibern für Windows, die die Fähigkeiten Ihrer Grafikkarte nutzen.

Um einen anderen Treiber zu installieren oder die Auflösung zu wechseln, schlagen Sie in Ihrem Windows-Handbuch nach und/oder fragen Sie den Hersteller Ihrer Grafikkarte nach Einzelheiten und spezifischen Informationen zu Ihrer Karte.

Wir empfehlen 640x480 im 256-Farben-Modus, obwohl auch höhere Auflösungen beeindruckende Ergebnisse liefern.

Netzwerkspiele

Wenn Sie Spaceward Ho! in einem Netzwerk ausführen, achten Sie darauf, dass SHARE läuft. Weitere Einzelheiten zur Dateifreigabe auf Ihrem System finden Sie in Ihrem DOS-Handbuch oder in Ihrer Netzwerkdokumentation.

Bevor Sie eine Spieldatei erstellen, achten Sie darauf, dass alle Spieler volle Lese- und Schreibrechte für das gewählte Verzeichnis auf dem Server haben. Benutzer ohne vollständigen Zugriff können dem Spiel nicht beitreten.

Achten Sie darauf, dass jeder Netzwerkspieler seine eigene lokale Kopie von Spaceward Ho! ausführt. Führt mehr als ein Netzwerkspieler dieselbe ausführbare Datei aus, können Spieldateien verstümmelt werden oder das Programm kann ausfallen.

Verwendung von Ton

MULTIMEDIA-TON VERWENDEN (Windows 3.1 und Windows 3.0 mit MPC-Erweiterungen)

Der Waveform-Ton des Windows-Multimediasystems wird unterstützt. Achten Sie darauf, dass Ihr System richtig für Ihre Tonhardware eingerichtet ist. Einzelheiten finden Sie in Ihrer Windows-Dokumentation.

DIE SOUNDBLASTER®-KARTE UNTER WINDOWS 3.0 VERWENDEN

Haben Sie eine SoundBlaster®-Karte in Ihrem System installiert und arbeiten unter Windows 3.0, können Sie möglicherweise die von Creative Labs, Inc. bereitgestellte Datei SNDBLST.DLL verwenden. Die SNDBLST.DLL lag Ihrer SoundBlaster®-Karte möglicherweise bei, oder Sie können sich direkt an Creative Labs wenden, um eine Kopie zu erhalten. Haben Sie die DLL in Ihr Windows-Verzeichnis installiert, sollte der folgende Abschnitt zu Ihrer Datei WIN.INI hinzugefügt werden:

[SoundBlaster] Port=220 Int=7 DMA=1

Ist Ihre SoundBlaster®-Karte mit anderen als den oben gezeigten Einstellungen (den Standardeinstellungen) konfiguriert, bearbeiten Sie die Datei WIN.INI und verwenden den richtigen Port und die richtige Interruptnummer für Ihre SoundBlaster®-Installation. Einzelheiten finden Sie in Ihrer SoundBlaster®-Dokumentation. (SoundBlaster® ist ein eingetragenes Warenzeichen von Creative Labs, Inc.)
