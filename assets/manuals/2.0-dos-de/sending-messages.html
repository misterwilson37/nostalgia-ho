Funksprüche senden

Sie können in einer Partie Spaceward Ho! anderen Spielern Funksprüche senden. Da die Computerspieler die Nachrichten verstehen und selbst senden können müssen, haben wir uns eine sehr einfache Sprache ausgedacht, die allgemein genug ist, damit Sie sich mit allen im Spiel verständigen können.

Um einen Funkspruch zu senden, wählen Sie im Menü „Galaxie“ einfach „Funkspruch senden“. Es erscheint ein Dialog, in dem Sie festlegen, an wen Sie senden, was Sie sagen und dergleichen. Am besten machen Sie sich mit allen Nachrichten vertraut, indem Sie sie einfach alle ausprobieren.

Die einzige Nachricht, die im Spiel wirklich eine Wirkung hat, ist, einen Planeten zu beanspruchen. Tun Sie das, wissen alle anderen Spieler, dass Sie dort eine Kolonie haben. Wie sie auf dieses Wissen reagieren, ist unterschiedlich – manche wissen, dass sie Sie in Ruhe lassen sollten, andere, wo sie zuschlagen können.

Die anderen Nachrichten wirken natürlich unterschiedlich auf den Empfänger. Sagen Sie einem Spieler, dass Sie ihn hassen, mag er Sie tendenziell weniger als zuvor. Sagen Sie, dass Sie ihn mögen, mag er Sie vielleicht auch, vielleicht aber nicht.

Die Computerspieler lügen in ihren Nachrichten gelegentlich, manche mehr als andere. (Beim Beanspruchen eines Planeten können Sie allerdings nicht lügen.)
