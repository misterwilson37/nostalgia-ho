Ein neues Spiel beginnen

Beim Start zeigt Spaceward Ho! einen Dialog, in dem Sie ein neues Spiel beginnen oder ein gesichertes fortsetzen können. Wählen Sie „Neues Spiel“. Danach müssen Sie Ihrer Galaxie einen Namen geben. Als Nächstes erscheint ein großer, furchteinflößender Dialog „Galaxis erstellen“. Klicken Sie einfach auf „Erstellen“. Spaceward Ho! fragt dann nach Ihrem Namen. Sobald Sie ihn eingegeben haben, können Sie loslegen.

Am besten lernen Sie Spaceward Ho!, indem Sie das Spiel beim ersten Mal spielen, während Sie das Handbuch lesen. Wir haben versucht, dieses Buch so zu ordnen, dass Ihre Fragen beantwortet werden, sobald sie auftauchen. Wir werden Ihnen nicht den Quatsch „Lesen Sie das ganze Handbuch gründlich, bevor Sie zu spielen anfangen“ auftischen. Setzen Sie sich hin und versuchen Sie sich am Spiel. Denken Sie nur daran, dass Sie Fragen haben werden und dieses Handbuch sie beantwortet.

Sie können auch im Menü „Optionen“ „Automatisch spielen“ einschalten und sehen, wie der Computer spielen würde. So bekommen Sie eine Vorstellung vom Ablauf, und Sie können das automatische Spielen jederzeit ausschalten und selbst übernehmen.
