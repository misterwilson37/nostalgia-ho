Kämpfe ansehen

Manchmal stoßen Ihre Schiffe auf Schiffe anderer Spieler. Dann kämpfen sie, bis eine Seite tot ist. Zugegeben, das macht ein friedliches Nebeneinander nicht leicht, aber dies ist ein Kriegsspiel. Jedenfalls wollen Sie nach einem Kampf wissen, was zum Kuckuck passiert ist. Es gibt ein paar Wege, das herauszufinden. Erstens: Wenn Sie im Menü „Optionen“ den Eintrag „Kämpfe immer ansehen“ angekreuzt haben, bekommen Sie zu Beginn jedes Zuges zusammen mit Ihren anderen Nachrichten eine Zusammenfassung der Kämpfe, die gerade stattgefunden haben.

Sie können auch einen beliebigen Stern auswählen und den letzten Kampf an diesem Stern ansehen, indem Sie im Menü „Galaxie“ den Eintrag „Kampf bei Proxima ansehen“ (oder wie der Stern heißt) wählen. Gab es an einem Stern zwei oder mehr Kämpfe, können Sie auf diese Weise nur den letzten sehen.

Auch ein Doppelklick auf einen Stern, an dem Sie einen Kampf hatten, der aber nicht Ihre Kolonie ist, zeigt den letzten Kampf. (Ein Doppelklick auf eine Kolonie öffnet den Dialog „Schiffe bauen“.)

Ein Klick auf eine Kampfzusammenfassung im Berichtsfenster zeigt Ihnen diesen Kampf. Gab es an einem Stern mehr als einen Kampf, können Sie auf diese Weise einen älteren Kampf ansehen.

Wie schnell Spaceward Ho! den Kampf abspielt, stellen Sie im Dialog „Kampfgeschwindigkeit einstellen…“ im Menü „Optionen“ ein. Wenn Sie die Option „Vollanimierte Kämpfe“ abwählen, schießt jeder Stapel von Schiffen gleichzeitig, und es gibt keine Explosionsgrafiken. Dadurch laufen Kämpfe viel schneller.

Verlieren Sie einen Kampf in der allerersten Runde, hatten Ihre Schiffskommandanten nicht genug Zeit, Ihnen Informationen über den Kampf zu schicken, bevor sie zerstört wurden. Sie wissen dann kaum, wie viele feindliche Schiffe dort waren – nur, dass es genug waren, um Sie zu vernichten.
