Préférences

La première fois que vous lancez Spaceward Ho!, un fichier de préférences nommé “Spaceward Ho! Prefs” est créé. Si vous avez le Système 7, il est créé dans le dossier Préférences du Dossier Système de votre disque de démarrage. Sinon, il est créé dans le même dossier que l’application Spaceward Ho!.

Nous y rangeons tout : l’endroit où vous aimez placer les fenêtres, si vous voulez le son ou pas, votre vitesse de bataille préférée, et ainsi de suite.

En outre, le fichier de préférences contient les noms des gens avec qui vous avez joué, les noms des vaisseaux que vous concevez et les étoiles que vous nommez pour avoir gagné la partie.

Pour repartir de zéro (par exemple si vous avez un jour donné à un vaisseau le nom de votre ex-petite amie toute neuve et que la vue de ce nom réveille de douloureux souvenirs), jetez simplement le fichier de préférences. Toutes ces informations seront effacées.

La plupart des préférences se règlent avec la boîte de dialogue “Préférences…” du menu “Options”.

Afficher les trajets des flottes

Cette option fait afficher à Spaceward Ho! une ligne pointillée quand vos flottes sont en route vers quelque part. À mesure que les flottes se rapprochent, la ligne raccourcit. C’est pratique et instructif.

Trier automatiquement la liste des planètes

Cela trie vos planètes par revenu à chaque tour. Vos meilleures planètes seront donc toujours en bas de la liste (puisque vous n’avez sans doute pas besoin de vous en occuper) et vos toutes nouvelles planètes seront tout en haut. Vous n’avez donc pas à chercher dans la liste les planètes qui vous intéressent. Vous pouvez désactiver cette option et simplement faire glisser les planètes pour les mettre dans l’ordre que vous voulez, comme avant, si vous le souhaitez. Nous ne le recommandons pas, cependant.

Afficher les messages d’événements

Si cet élément est sélectionné, tous les messages d’événements s’affichent dans le coin inférieur gauche de la carte au début de chaque tour. Cliquez sur le message ou appuyez sur Retour pour passer au suivant.

Tous les messages apparaissent dans la fenêtre des rapports, que cet élément soit coché ou non.

Revoir les batailles annoncées

Cet élément n’a d’effet que si celui qui est au-dessus, « Afficher les messages d’événements », est aussi coché. Si les deux le sont, chaque fois qu’un message de bataille est sur le point d’être affiché, la bataille est automatiquement rejouée. S’il n’est pas coché, seul le message de résumé s’affiche.

Régler la vitesse des batailles

Vous pouvez régler ici la vitesse des tirs et des explosions dans les revues de bataille. Si vous vous ennuyez à regarder les batailles, accélérez-les. Cocher « Les piles tirent ensemble » accélère considérablement les batailles, surtout les très grandes. Décocher « Animation complète » supprime les images d’explosion, ce qui rend les batailles encore plus rapides.

Régler la fréquence de consultation

La fréquence de consultation détermine à quelle cadence l’ordinateur vérifie le fichier de la partie pour savoir qui a fini son tour et qui ne l’a pas fini. Plus la consultation est fréquente, plus vite l’ordinateur saura que tout le monde a terminé. Hélas, si vous jouez avec beaucoup de monde sur un réseau lent (AppleTalk plutôt qu’EtherTalk), gardez une fréquence de consultation assez longue pour éviter un trafic réseau excessif.
