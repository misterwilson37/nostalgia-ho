Préférences

La première fois que vous lancez Spaceward Ho!, un fichier de préférences nommé « Spaceward Ho! 5.0 Prefs » est créé dans le dossier Préférences du Dossier Système de votre disque de démarrage.

Nous y rangeons tout : l’endroit où vous aimez placer les fenêtres, si vous voulez le son ou pas, votre vitesse de bataille préférée, et ainsi de suite.

En outre, le fichier de préférences contient les noms des gens avec qui vous avez joué, les noms des vaisseaux que vous concevez et les étoiles que vous nommez pour avoir gagné la partie.

Pour repartir de zéro (par exemple si vous avez un jour donné à un vaisseau le nom de votre ex-petite amie toute neuve et que la vue de ce nom réveille de douloureux souvenirs), jetez simplement le fichier de préférences. Toutes ces informations (y compris vos master points hors réseau !) seront effacées.

La plupart des préférences se règlent avec “Préférences… ”.

Afficher les messages d’événements

Si cet élément est coché, les messages d’événements s’affichent dans le coin inférieur gauche de la carte au début de chaque tour. Cliquez sur le message ou appuyez sur Retour pour passer au suivant. Tous les messages apparaissent dans la fenêtre des rapports, que cet élément soit coché ou non.

Mais seulement les plus importants

Cela élimine beaucoup de messages de « bavardage », comme quand des vaisseaux se ravitaillent ou quand vous dépensez de l’argent pour terraformer des étoiles non rentables. Cela conserve les messages de bataille et de progrès technologique, ainsi que les supernovas et autres événements du genre.

Revoir les batailles

Cet élément n’a d’effet que si celui qui est au-dessus, « Afficher les messages d’événements », est aussi coché. Si les deux le sont, chaque fois qu’un message de bataille est sur le point d’être affiché, la bataille est automatiquement rejouée. S’il n’est pas coché, seul le message de résumé s’affiche.

Vitesse de la revue des batailles

Vous pouvez régler ici la vitesse des tirs et des explosions dans les revues de bataille. Si vous vous ennuyez à regarder les batailles, accélérez-les. Cocher « Les piles tirent ensemble » accélère considérablement les batailles, surtout les très grandes. Décocher « Animation complète » supprime les images d’explosion, ce qui rend les batailles encore plus rapides.

Sauvegarde automatique à chaque tour

Si cette case est cochée, Spaceward Ho! sauvegarde la partie dans son fichier de parties à chaque tour, de sorte que si le courant est coupé de façon inattendue, vous pouvez reprendre exactement où vous en étiez.

Vocaliser les mots-clés du chat

Cela fait jouer à Spaceward Ho! des sons quand certains mots apparaissent dans la fenêtre de discussion. Par exemple LOL, hehe et le préféré #$&@ !
