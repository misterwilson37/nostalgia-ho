Installer Spaceward Ho!

Le mieux est d’installer Spaceward Ho! sur votre disque dur. Vous pouvez le lancer depuis le CD si vous voulez, mais c’est plus lent, et plus agaçant.

Pour installer Spaceward Ho!, faites simplement glisser son icône depuis le CD fourni dans cette boîte jusqu’à votre disque dur.

D’habitude, nous sommes si brefs que ce serait toute l’explication. Mais comme nous essayons de remplir le manuel, nous allons passer en revue tous les problèmes que vous pourriez rencontrer.

Problèmes d’installation possibles

Mon Mac affiche une boîte de dialogue qui parle de disque plein.

Ce n’est qu’une intuition, mais peut-être que votre disque dur n’a plus assez de place pour le jeu. Jetez quelques trucs inutiles de votre disque dur, comme ces 200 copies de TeachText, les dossiers Système en trop ou King’s Quest LXII.

Je n’ai pas le CD.

Il a dû se perdre quelque part, à moins que vous ne fassiez du piratage stupide en copiant la documentation au lieu du logiciel. Cherchez-le. Peut-être avons-nous oublié de mettre un disque dans la boîte. Peut-être est-il tombé. Peut-être que votre chien l’a mangé. (Si vous n’avez pas de chien, venez chercher le nôtre.) Si vous ne le trouvez pas, appelez-nous, nous vous gronderons et vous enverrons un remplacement.

Bien sûr, si vous l’avez téléchargé sur le web, vous n’aurez pas de CD. Mais dans ce cas, vous n’aurez pas à l’installer sur votre disque dur, puisqu’il y sera déjà. Dans ce cas, toute cette histoire d’installation ne vaut probablement pas la peine d’être lue.

Je n’ai pas de Macintosh.

Vous commencez à faire le malin. Achetez un Macintosh. Il vous plaira.

Should I stay, or should I go?

If you stay, there will be trouble. If you go, it will be double. Ou est-ce l’inverse ?
