Corriger les dépenses

La commande « Corriger les dépenses » se trouve dans le menu « Galaxie ». Elle fait plusieurs choses.

Si vous ne dépensez pas assez pour certaines planètes (sans atteindre le trait noir), juste assez d’argent est ajouté pour toucher ce trait noir. L’argent est prélevé sur votre épargne : si vous n’avez pas d’épargne, il ne se passe rien. Si vous dépensez zéro pour cent pour une planète, la commande suppose que vous voulez l’abandonner et ne corrige pas ses barres de dépenses.

Si vous dépensez trop pour certaines planètes (plus d’argent que nécessaire pour terraformer, extraire et construire les vaisseaux actuellement en file d’attente), la barre de la planète est abaissée au niveau juste suffisant pour payer ce qui doit être fait. L’argent en trop est versé à l’épargne.

Pour chaque barre corrigée, un message apparaît dans le coin inférieur gauche de la carte des étoiles. Si des messages de tour ordinaires sont encore affichés dans le coin inférieur gauche, l’option « Corriger les dépenses » est grisée jusqu’à ce que vous les ayez tous passés.
