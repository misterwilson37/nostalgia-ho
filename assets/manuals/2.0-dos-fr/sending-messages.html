Envoyer des messages

Vous pouvez envoyer des messages aux autres joueurs d’une partie de Spaceward Ho! Comme les joueurs ordinateur doivent pouvoir comprendre les messages et en envoyer eux-mêmes, nous avons conçu un langage très simple, assez universel pour que vous communiquiez avec tout le monde dans la partie.

Pour envoyer un message, choisissez simplement « Envoyer un message » dans le menu « Galaxie ». Une boîte de dialogue s’ouvre et vous permet de décider à qui envoyer, quoi dire, et ainsi de suite. Le meilleur moyen de vous familiariser avec tous les messages est de les essayer tous.

Le seul message qui ait un réel effet dans le jeu est celui qui revendique une planète. Quand vous le faites, tous les autres joueurs savent que vous y avez une colonie. Leur réaction à cette information varie : certains sauront qu’il vaut mieux vous laisser tranquille, d’autres sauront où frapper.

Les autres messages, bien sûr, auront des effets variables sur la personne qui les reçoit. Si vous dites à un joueur que vous le détestez, il aura tendance à moins vous apprécier qu’avant. Si vous dites que vous l’aimez bien, il vous aimera peut-être en retour, ou peut-être pas.

Les joueurs ordinateur mentent parfois dans leurs messages, certains plus que d’autres. (Vous ne pouvez toutefois pas mentir en revendiquant une planète.)
