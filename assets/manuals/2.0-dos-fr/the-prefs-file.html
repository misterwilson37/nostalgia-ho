Le fichier de préférences

La première fois que vous lancez Spaceward Ho!, un fichier de préférences nommé « Spaceward Ho! Prefs » est créé. Si vous avez le Système 7.0, il est créé dans le dossier Préférences du Dossier Système de votre disque de démarrage. Sinon, il est créé dans le même dossier que l’application Spaceward Ho!.

Nous y rangeons tout : l’endroit où vous aimez placer les fenêtres, si vous voulez le son ou pas, votre vitesse de bataille préférée, et ainsi de suite.

En outre, le fichier de préférences conserve les noms de toutes les personnes avec qui vous avez joué, les noms de tous les vaisseaux que vous avez conçus et toutes les étoiles que vous avez nommées pour avoir gagné la partie.

Pour repartir de zéro (par exemple si vous avez un jour donné à un vaisseau le nom de votre ex-petite amie toute neuve et que la vue de ce nom réveille de douloureux souvenirs), jetez simplement le fichier de préférences. Toutes ces informations seront effacées.
