Instructions ultra-rapides pour le Ho!

Voici le résumé en un paragraphe de ce que vous devez savoir.

Jouez avec les barres pour ajuster les dépenses. Cliquez sur les messages de la carte pour les faire disparaître. Faites glisser d’une étoile à l’autre pour déplacer les vaisseaux. Expérimentez. Conquérez la galaxie.
