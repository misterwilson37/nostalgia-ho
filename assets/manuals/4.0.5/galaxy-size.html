Creating Custom Galaxies

Galaxy Size

The Galaxy Size determines how big the galaxy is. The bigger the galaxy, the more room there is for each player to roam. In a small galaxy with many players, the game will tend to be heated and fast. In a large galaxy with only a few players, the game will develop for a long time before there's any combat. Games in humongous galaxies will take forever.
