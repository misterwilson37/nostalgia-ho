Setting up a Multiplayer Game

To play Spaceward Ho! IV over a network, one player must Create the Galaxy on a file server that all the players have access to (either a separate server, or through file-sharing in Windows). All players must open that game to join, and then click the Everyone’s Ready button.

If a network game is in progress, you can take over for a computer player by opening the game and typing in your name as a new player.

The multiplayer screen will look like a single player game, and this is intentional. It can be difficult to differentiate between the human and computer players (except that humans are generally more devious).

You can communicate directly with other humans through the chat window (Ctrl-3 to toggle the chat window open or closed). Computer players never communicate in the chat window.
