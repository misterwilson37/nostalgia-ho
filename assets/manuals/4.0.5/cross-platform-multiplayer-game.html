Creating Custom Galaxies

Cross-Platform Multiplayer Game

Spaceward Ho! can be played as a cross-platform game between the Win95 and Macintosh versions (version 4.0.5 or higher). Here are a few simple rules to follow when setting up and playing a cross-platform game:

All cross-platform games must be started on a Macintosh (otherwise Macs won’t be able to join in on the fun).

You must include the file extension .Ho! to the name of your Galaxy File (otherwise the Win95 machines won’t be able to join in on the fun).

You won’t be able to include the asterisk (*), question mark (?) or backslash (\) characters in your filename (these characters are reserved in Win95 for special purposes).
