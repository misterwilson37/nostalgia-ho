The Options Menu

Set Polling Time

The polling time determines how often the computer checks the game file to see who has finished their turn and who hasn't. The faster the polling time, the sooner the computer will know when everyone's done. Alas, if you're playing with a lot of people on a slow network keep the polling time pretty long to avoid excessive network traffic.
