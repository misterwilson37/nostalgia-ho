Schiffe

Mit Schiffen erkunden Sie neue Sterne, verteidigen Ihre Kolonien und kolonisieren neue Planeten. Es gibt mehrere Arten von Schiffen, und Sie können eigene entwerfen.

Die Schiffe in Spaceward Ho! sind unglaublich groß und teuer. Ihr erstes Kolonieschiff verschlingt zum Beispiel fast ein Drittel der gesamten Ressourcen Ihres Planeten sowie die gesamte industrielle Produktion des Planeten über dreißig Jahre. Es ist ein großer Kahn.

Schiffe bauen

Schiffe können Sie in jeder Ihrer Kolonien bauen. Klicken Sie dazu auf den Planeten, auf dem Sie Schiffe bauen wollen, und wählen Sie im Menü „Schiffe“ den Eintrag „Schiffe bauen/entwerfen…“ oder doppelklicken Sie einfach auf den Planeten. Ein großer Dialog erscheint. In diesem Dialog können Sie sowohl Schiffe bauen als auch neue Schiffstypen entwerfen.

Links im Dialog sehen Sie eine Liste der verfügbaren Schiffstypen. Wenn keiner davon Ihrem Geschmack entspricht, können Sie unten rechts mit den Schiebereglern eine neue Klasse entwerfen.

Schiffe bewegen

Um eine Flotte zu bewegen, klicken Sie einfach auf den Planeten, auf dem sie steht, und ziehen dorthin, wohin sie fliegen soll. Wenn Sie das Ziel erreichen können, sehen Sie einen Pfeil entlang der Route der Flotte. Lassen Sie die Maus los, hören Sie ein „Hyahh!“, das Ihnen sagt, dass der Kurs gesetzt ist. Wenn Sie den Zug beenden, fliegt das Schiff los.

Kann die Flotte den Stern, zu dem Sie gezogen haben, nicht erreichen, wird der Weg als gepunktete graue Linie angezeigt. Hat die Flotte genug Treibstoff, um zu dem ausgewählten Stern und wieder zurück zu fliegen, ist der Weg ein Doppelpfeil.

Damit eine Flotte stillhält oder ihre Bewegung abgebrochen wird, klicken Sie auf den Planeten der Flotte und halten die Maustaste eine Sekunde gedrückt. Haben Sie es richtig gemacht, hören Sie beim Loslassen der Maus ein „Whoa!“.

Haben Sie an einem Planeten mehr als eine Flotte, wählen Sie die zu bewegende Flotte, indem Sie in den Budgetinformationen auf ihren Namen klicken. Hat eine Flotte ein Ziel und will sich bewegen, wenn Sie den Zug beenden, steht ihr Name fett, damit Sie es wissen. Drücken Sie die Taste TAB, wählt das Spiel automatisch die nächste Flotte an diesem Planeten.

Eine Flotte tankt automatisch auf, sobald sie einen Planeten erreicht, der Ihnen oder Ihren Verbündeten gehört. Hat eine Flotte nicht genug Treibstoff zum Abflug, können Sie ein Kolonieschiff zu diesem Planeten schicken, ihn einen Zug lang kolonisieren und dann alle abfliegen lassen. Das heißt, ein Kolonieschiff dient auch als Tanker.

Der Kurs einer Flotte kann nicht geändert werden, solange sie zwischen Planeten ist – im Hyperraum gibt es kein Zurück.

Flotten ordnen

Manchmal möchten Sie eine Flotte in Teile aufteilen oder mehrere Flotten zusammenlegen. Wählen Sie dazu im Menü „Schiffe“ den Eintrag „Flotten ordnen…“. Klicken Sie dann auf die Schiffe und ziehen Sie sie hin und her, bis sie so verteilt sind, wie Sie es wollen. Leider kann eine Flotte nur Schiffe desselben Typs enthalten (um die Dateigröße zu verringern).

Flotten und Schiffe verschrotten

Im Lauf des Spiels werden Sie feststellen, dass Metall knapp ist und Ihre veralteten Schiffe so gut wie nutzlos sind. Vielleicht möchten Sie einige Ihrer älteren Schiffe loswerden. 75 % des Metalls einer Flotte an Ihren Kolonien holen Sie zurück, indem Sie die Flotte verschrotten (wählen Sie im Menü „Schiffe“ den Eintrag „Aktuelle Flotte verschrotten“). Oder Sie verschrotten einen ganzen Schiffstyp (klicken Sie im Dialog „Schiffe…“ bei einem bestimmten Typ auf „Diesen Typ verschrotten“).

Wenn Sie einen Schiffstyp oder eine Flotte zum Verschrotten markieren, wird sie erst verschrottet, wenn Sie den Zug beenden. Bekommen Sie bis dahin kalte Füße, können Sie einfach im Dialog „Schiffe…“ auf die Taste „Typ nicht verschrotten“ klicken oder im Menü „Schiffe“ den Eintrag „Flotte nicht verschrotten“ wählen.

Wollen Sie nur einen Teil einer Flotte verschrotten, teilen Sie die Flotte im Dialog „Flotten ordnen…“ in die Schiffe, die Sie behalten wollen, und die, die Sie verschrotten wollen.

Verschrotten Sie Schiffe, die sich über einer Kolonie befinden, geht das Metall sofort in Ihren globalen Vorrat, und Sie können es sofort verwenden. Gehört Ihnen der Planet unter den Schiffen nicht, fällt das Metall auf den Planeten. Wer ihn als Nächster kolonisiert, kann dann das Metall Ihrer verschrotteten Schiffe abbauen.

Schiffe entwerfen

Das ist vielleicht der coolste Teil des Spiels. Wenn Ihre Technik steigt, werden Sie anfangen wollen, fortschrittlichere Schiffe mit diesen neuen Technologien zu bauen. Das ist leicht. Stellen Sie im Dialog „Schiffe bauen/entwerfen…“ einfach die Technikstufen so ein, wie Ihr neuer Typ sein soll. Sie bewegen dazu nur die Schieberegler, um die Eigenschaften des neuen Schiffs festzulegen. (Das rechte Ende des Schiebereglers entspricht immer Ihrer aktuellen Technikstufe.) Wenn Ihr Schiff so ist, wie Sie es wollen, bauen Sie einfach eines (mit der Taste „+“), und der Prototyp wird automatisch entworfen und gebaut.

Es gibt vier große Schiffsklassen: Kolonieschiffe, Satelliten, Späher und Kampfschiffe.

Kolonieschiffe

Kolonieschiffe befördern Menschen und kolonisieren für Sie neue Sterne. Kolonieschiffe sind unglaublich teuer, sowohl an Geld als auch an Metall. Sie kosten so viel, dass Sie nur wenige davon bauen wollen. Das, und weil Miniaturisierung ihnen nicht viel nützt, bedeutet, dass Sie bei Ihren Kolonieschiffen wahrscheinlich gar keine Miniaturisierung einsetzen wollen. Kolonieschiffe sind außerdem das Erste, auf das der Feind im Kampf schießt, also sollten Sie auch deshalb vorsichtig mit ihnen sein.

Satelliten

Satelliten sind Schiffe ohne Triebwerke. Das heißt, ihre Reichweite ist null. Satelliten sind ein billiges, wirksames Mittel, Ihre Planeten gegen feindliche Angriffe zu verteidigen. Leider können sie sich nicht bewegen; sie können nur den Planeten verteidigen, auf dem sie gebaut wurden. Satelliten sind viel kleiner als normale Schiffe, sodass es nicht so viele Treffer braucht, sie zu zerstören. Natürlich braucht man zum Bau von Satelliten auch längst nicht so viel Metall wie für Kampfschiffe.

Hat ein Planet Satelliten, hat er auf der Sternkarte einen Ring um sich.

Späher und Kampfschiffe

Späher und Kampfschiffe sind Ihre Grundschiffe. Der Unterschied zwischen Spähern und Kampfschiffen ist ein Kompromiss zwischen Triebwerken und Waffen. Späher können eine Reichweite haben, die zwei Einheiten über Ihrer Reichweitentechnik liegt. Leider liegt ihre maximale Waffen- und Schildtechnik eine Stufe unter Ihren aktuellen Stufen. Das macht Späher ideal zum Erkunden, aber nicht besonders gut im Kampf.

Spaceward Ho! setzt jeden Späher automatisch in seine eigene Flotte, damit er unabhängig losfliegen und erkunden kann. Kampfschiffe schließen sich automatisch zu einer Gruppe zusammen.

Entwicklungskosten

Der Bau des Prototyps eines neuen Schiffstyps kostet mehr als der der folgenden – es braucht Mühe, die Macken auszubügeln und zu testen. Das gilt besonders für Schiffe mit hoher Miniaturisierung. Denken Sie daran, dass die Entwicklungskosten einmalig sind und zu jedem neuen Schiffstyp gehören.
