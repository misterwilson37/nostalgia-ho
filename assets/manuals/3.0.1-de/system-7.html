System 7

Am besten spielen Sie Spaceward Ho! unter System 7. Mit System 7 können Sie jeden Computer zu einem Computer und einem Dateiserver machen. So kann jemand auf seinem Rechner ein Spiel erstellen und andere sich anmelden und mitspielen lassen. Schalten Sie dazu FileShare ein, indem Sie, nachdem Sie Ihren Spielordner oder Ihre Festplatte gewählt haben, im Menü „Datei“ den Eintrag „Freigabe…“ wählen. Wahrscheinlich müssen Sie auch das Kontrollfeld „Benutzer & Gruppen“ verwenden.

Wir haben ein paar besondere Funktionen im Hinblick auf FileShare eingebaut. Eine davon ist die Option „Ich aktualisiere die Züge“. Wenn jemand das Spiel auf dem Dateiserver spielt, soll diese Person die Züge auf ihrem eigenen Rechner aktualisieren, damit nicht alle Spielinformationen über das Netzwerk laufen müssen. Das ist viel schneller, da Festplatten schneller sind als Netzwerke. Lassen Sie jedenfalls in diesem Fall die Person, die das Spiel gestartet hat, diese Option wählen, während alle anderen sie ausschalten. So wird der Zug nicht über das Netzwerk aktualisiert. Haben alle ihren Zug beendet, aktualisiert ihn der Rechner mit angekreuztem „Ich aktualisiere die Züge“, und alle anderen bekommen dann die Ergebnisse.

Das kann auch praktisch sein, wenn die Spieler Rechner unterschiedlicher Geschwindigkeit haben, auch wenn Sie noch kein System 7 haben. Der Typ am Quadra kann die Züge aktualisieren, während die Leute an ihren Mac Classics es einfach ihn machen lassen.
