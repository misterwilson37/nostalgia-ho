Kämpfe ansehen

Manchmal stoßen Ihre Schiffe auf Schiffe anderer Spieler. Dann kämpfen sie, bis eine Seite tot ist. Zugegeben, das macht ein friedliches Nebeneinander nicht leicht, aber dies ist ein Kriegsspiel. Jedenfalls wollen Sie nach einem Kampf wissen, was zum Kuckuck passiert ist. Es gibt ein paar Wege, das herauszufinden. Erstens: Wenn Sie im Dialog „Einstellungen…“ den Eintrag „Kämpfe ansehen“ angekreuzt haben, bekommen Sie zu Beginn jedes Zuges eine Zusammenfassung der Kämpfe.

Sie können auch einen beliebigen Stern auswählen und den letzten Kampf an diesem Stern ansehen, indem Sie im Menü „Galaxis“ den Eintrag „Kampf bei Proxima ansehen“ (oder wie der Stern heißt) wählen. Gab es an einem Stern zwei oder mehr Kämpfe, können Sie auf diese Weise nur den letzten sehen.

Doppelklicken Sie auf einen Stern, um den letzten Kampf dort anzusehen.

Klicken Sie im Berichtsfenster auf eine Kampfzusammenfassung, um diesen Kampf anzusehen. Gab es an einem Stern mehr als einen Kampf, können Sie auf diese Weise einen älteren Kampf ansehen.

Wie schnell Spaceward Ho! den Kampf abspielt, stellen Sie im Dialog „Einstellungen…“ ein.

Verlieren Sie einen Kampf in der ersten Runde, haben Ihre Schiffskommandanten nicht genug Zeit, Ihnen Informationen über den Kampf zu schicken, bevor sie zerstört werden. Sie wissen dann kaum, wie viele feindliche Schiffe dort sind – nur, dass es genug sind, um Sie zu vernichten.
