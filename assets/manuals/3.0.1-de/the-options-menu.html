Das Menü „Optionen“

Unten finden Sie eine Zusammenfassung der Einträge im Menü „Optionen“.

Automatisch spielen

Bei „Automatisch spielen“ erledigt der Computer Ihren Zug automatisch.

Wenn Sie den Computer für sich spielen lassen, entwickelt er eine eigene Strategie, genau wie die normalen Computergegner. Das ist für Anfänger ein guter Weg zum Lernen. Es ist auch sehr praktisch, wenn Sie kurz vor dem Sieg (oder der Niederlage) stehen, das Spiel aber nicht selbst zu Ende spielen wollen. Wählen Sie diese Option auch, wenn Sie eine Mehrspielerpartie vorzeitig verlassen müssen, Ihr Gebiet aber nicht völlig zerfallen soll.

Auch wenn der Computer für Sie spielt, behalten Sie etwas Kontrolle. Der Computer ändert nie Ihre Balken für die Technikausgaben. Wenn Sie Schiffe bauen, setzt der Computer sie ein. Wenn Sie Schiffe irgendwohin schicken, lenkt der Computer sie nicht um, bevor sie ihr Ziel erreicht haben. Der Computer versucht im Allgemeinen, die Kolonien zu behalten, die Sie haben, es sei denn, er hält sich für zu weit ausgedehnt.

Wählen Sie „nur meinen Zug als beendet markieren“, geschieht auch nur das. Keiner Ihrer Budgetbalken ändert sich je (außer wenn Sie Planeten verlieren oder gewinnen). Das ist eine praktische Option, wenn mehrere Züge hintereinander nichts Interessantes passiert, etwa wenn Sie darauf warten, dass eine Kolonie rentabel wird.

Wählen Sie „Ich spiele meine Züge selbst“, um das automatische Spielen auszuschalten.

Der Schieberegler unten im Dialog „Automatisch spielen“ bestimmt, wie lange jede Nachricht angezeigt wird. Normalerweise müssen Sie jede Nachricht anklicken, damit sie verschwindet. Beim automatischen Spielen können Sie weiterhin klicken, aber läuft die Zeit ab, verschwindet sie von selbst. Das ist nur wichtig, wenn Sie dem Computer beim automatischen Spielen zusehen.

Den Stil des Computerspiels legen Sie fest, wenn Sie ihn auf automatisches Spielen schalten. Die Schieberegler im Dialog „Automatisch spielen“ bestimmen, wie sehr Ihr Computer zum Angreifen und Verteidigen neigt. Probieren Sie die Regler aus – Sie kommen schon dahinter.

Ich aktualisiere die Züge

Sind in einem Mehrspielerspiel einige Macs schneller als andere, sollen vermutlich die schnellen Macs die Züge aktualisieren. Lassen Sie die Macs, die den Zug nicht aktualisieren sollen, diese Option abwählen.

Arbeiten Sie mit FileShare oder etwas Ähnlichem, richten Sie es so ein, dass die Person, die die Spieldatei auf ihrem eigenen Rechner hat, den Zug aktualisiert. Alle anderen wählen diese Option also ab.

Hat niemand diese Option gewählt, wird der Zug nie aktualisiert. Das ist schlecht.

Die Ruhmeshalle und die Halle der Schande

Gewinnen Sie eine Partie Spaceward Ho!, werden die Angaben zu Ihrem Sieg in der Ruhmeshalle festgehalten. Verlieren Sie, kommen diese Angaben (so peinlich sie auch sind) in die Halle der Schande. So können Sie Ihre Fortschritte festhalten und bekommen eine Rangfolge, mit der Sie sich mit anderen Spielern vergleichen können.

Die „Schwierigkeit“ hängt davon ab, wie schwer wir Ihr Spiel eingeschätzt haben. Natürlich hat ein Spiel gegen schlaue Spieler mit Ihnen als „Experte“ eine höhere Schwierigkeit als ein Spiel gegen dumme Spieler mit Ihnen als „Neuling“. Auch einiges andere zählt, etwa die Zahl der Verbündeten, mit denen Sie den Sieg geteilt haben, wie groß die Galaxie war und wie lange Sie bis zur Siegeserklärung gebraucht haben.

Eine großartige Funktion der Ruhmeshalle ist, dass Sie Spiele, die jemand anderes gewonnen hat, oder ein Spiel, das Sie zuvor verloren haben, noch einmal spielen können. So können Sie andere Strategien ausprobieren und sich auf eine weitere Art mit anderen Spielern messen.

Wollen Sie Ihre Ruhmeshalle jemals leeren, werfen Sie einfach die Datei „Ho! 3.0 Prefs“ weg.
