Bündnisse

In Spaceward Ho! 3.0 können Sie sich mit den anderen Spielern verbünden, ob Mensch oder Computer. Kurz gesagt: Haben Sie ein Bündnis geschlossen, kämpfen Sie nicht mehr gegen diesen Spieler. Treffen Sie auf Schiffe oder Planeten von Verbündeten, bestehen Sie einfach friedlich nebeneinander. An verbündeten Planeten können Sie auch auftanken.

Um ein Bündnis zu schließen, müssen natürlich beide Spieler es wollen. Ihre Meinung über die anderen Spieler zeigen Sie im Dialog „Bündnisse…“ im Menü „Galaxis“. Dort sehen Sie auch, was sie von Ihnen halten.

Das Spiel sorgt bei Verbündeten eigentlich nur dafür, dass sie sich nicht gegenseitig töten. Vermutlich wollen Sie Informationen mit Ihren Verbündeten teilen. Sie können ihnen auch Geld und Metall geben, wenn sie es am dringendsten brauchen. (Das geht im Dialog „Geld/Metall geben…“.)

Ein Bündnis lösen Sie, indem Sie den betreffenden Außerirdischen im Dialog „Bündnisse…“ aus der Spalte „Mag ich“ in die Spalte „Mag ich nicht“ verschieben. Sie kämpfen dann überall auf Leben und Tod, wo Sie bisher nebeneinander bestanden haben. Nebenbei erwerben Sie damit auch seinen dauerhaften Hass und sein Misstrauen.
