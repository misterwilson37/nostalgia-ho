Ships Menu Commands

List Ship Types... Displays a list of the currently available ship types. Use the slider bar to scroll through the list of ship types. You can select a ship by clicking on its picture. Information about the selected ship is displayed beneath the larger picture of the vessel describing its costs and its capabilities. If you wish to scrap all the ships of a given type, and discontinue that type for future turns, click on the check box named "Scrap this type". This ship type will then be scrapped when you end your turn.

Create New Ship Type...

This allows you to design new ships to reflect your new technology levels. The Create New Ship dialog contains slider controls for adjusting the Range, Speed, Weapons, Shields, and Miniaturization up to your current technology levels. The drop-down combo box beneath the ship picture is used to select the type of ship you wish to design. Information about the cost of building this ship -- development and production -- is shown below the picture. You can type in a name for your new ship type, or let the computer choose an appropriate name for you.

List All Fleets... This will bring up a list of all the fleets you currently control, and tell you where they are or where they're going.

Organize ships... This allows you to divide existing fleets of the selected type into smaller groups, or to combine existing fleets of the selected type into larger groups.

Build Ships at Star... Select this to build ships at the selected star. Choose the ship type you wish to build from the list to the right. Each click on the ship picture in the list will add one more ship to the number in the queue. Clicking on the ship picture in the queue area will remove one ship from the queue. Up to three ship types can be queued at one time.

Scrap Current Fleet... This will cause the selected fleet to be scrapped at the end of your turn, returning some of the metal from them into your resources.

Review Battle at Star... This will replay the last battle that occurred at that star. If the last battle to take place there occurred more than 500 years ago, then the battle information will no longer be available.
