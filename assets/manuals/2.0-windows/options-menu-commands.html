Options Menu Commands

Force Turn Update Forces the turn to end even if all the other players have not yet ended their turn.

Auto Play... Allows the computer to play for you, or to just mark you done at the end of each turn.

I'll Update Turns In a multi-player game, slower computers may want to turn this switch off to allow turn updates to be handled by the faster machine (at least one machine in the game must have this option set).

Set Polling Time... Longer polling times report turn updates less often, but may free up time for the computer.

Set Battle Speed... This controls the speed of the animation in reviewed battles. If "Fully Animated Battles" is unchecked, the battles are less animated (no explosions; entire stack shoots at once).

Show Event Messages

If this option is off, you will not receive messages of events each turn.

Review Announced Battles

If this option is off, you will not get an automatic battle review of the battles you were engaged in during the turn.

Give Overspending Warnings

If this option is off, you will not receive notice of overspending in any area.

Sound This option toggles the game sound on or off.
