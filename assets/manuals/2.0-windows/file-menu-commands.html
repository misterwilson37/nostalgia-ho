File Menu Commands

New... Creates a New Galaxy. You are first asked for the name of the galaxy (this is a file name). You then choose the size, shape, and density of the galaxy and the intelligence of the computer opponents you play against. Select these options by clicking on the icons. Use the slider bar to choose the number of computer opponents in a game. If you will have other human players, they will join after your galaxy has been created (although the total number of players - human and computer - must be no more than twenty).

Open... Opens an existing galaxy to continue or Join. You must enter your name and -- if you choose -- a password.

Save... Saves the current game.

Revert to saved... Reverts the game to the previously saved turn.

Close... Closes the current game.

End Turn Ends the turn and saves the current player to disk.

End Turn & Switch Players...

Ends the turn and allows another player to log into the same game.

Page Setup... Brings up the printer setup dialog.

Print Map... Prints the current galaxy map on your default printer.

Exit Quits Spaceward Ho!
