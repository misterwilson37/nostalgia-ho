Playing on a network

Playing Spaceward Ho! on a network

The ultimate Ho! experience is to play against other humans on a network. You can play any combination of computer and human opponents in the same game (up to a total of 20 players).

The network support for Spaceward Ho! relies on shared files. Each player who will join the game must be able to access the disk where the game file is stored from his computer.

Have someone create the Galaxy on a file server where everybody can get at it. Then have everyone open the game -- one at a time, since the file server can only accommodate one user at a time.

(Note: Make sure the computer being used as the server is running SHARE)

The first person to join becomes the "System Administrator." His is the only one with the ability to say when the first turn should be processed. When everyone who had joined the game has ended their first turn, an alert will appear on the game administrator's computer, telling him how many people have entered the game and asking him whether he wants to proceed to the next turn. Once the game has progressed beyond the year 2000, no one else can join, so if the number of people registered is fewer than the administrator expects, he must click on the "Wait" button and find out who hasn't logged in. Once they have logged in and ended their turns, the alert will reappear showing a greater number of human players.
