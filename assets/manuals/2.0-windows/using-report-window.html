Using the Report Window

The Report Window can be made visible by selecting it from the Window menu. It can be hidden in the same way. (You can also use Alt-2 to do this). The Report Window contains a record of past messages. If you wish to review a message, you may find it by scrolling through the list in the Report Window. You can move the Report Window anywhere on the screen, and can change its size as you like (vertically only) . Clicking on the messages in the report window may produce some effect, depending upon the message -- for example, it may change the selected star to the star mentioned in the message, or it may replay a previous battle.
