Using Tech Spending Window

Using the Tech Spending Window

The Tech Spending Window can be made visible by selecting it from the Window menu. It can be hidden in the same way. (You can also use Alt-1 to do this). You can move the Tech Spending Window anywhere on the screen you like.

The bar controls depict the relative amount of money that is being spent in each of

five different areas of technology research. You can adjust these relative amounts by clicking on the bar you wish to affect and dragging it to its new position.
