El archivo de preferencias

La primera vez que ejecutes Spaceward Ho!, se creará un archivo de preferencias llamado “Spaceward Ho! Prefs”. Si tienes System 7.0, se creará en la carpeta Preferencias de la Carpeta del Sistema de tu disco de arranque. Si no, se creará en el mismo directorio que la aplicación Spaceward Ho!.

Guardamos todo en el archivo de preferencias: dónde te gusta colocar las ventanas, si quieres el sonido activado o desactivado, tu velocidad de batalla preferida, etcétera.

Además, el archivo de preferencias guarda los nombres de todas las personas con las que has jugado alguna vez, todos los nombres de las naves que has diseñado alguna vez y todas las estrellas a las que has puesto nombre por ganar la partida.

Para empezar de cero (por ejemplo, si una vez pusiste a una nave el nombre de tu nueva exnovia y ver su nombre te trae recuerdos dolorosos), basta con tirar el archivo de preferencias. Toda esta información se borrará.
