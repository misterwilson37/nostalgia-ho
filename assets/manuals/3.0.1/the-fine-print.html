You may put this software on your hard disk. You may make as many backup copies as you wish. You may duplicate the game so that friends may join in a network game with you, so long as you ensure that they can not run any game without you in it.

Basically, we subscribe to the “Monopoly Theory” of multi-player games. When you purchase a board game, only one copy is necessary for as many people to play in a game together as the game supports. On the other hand, duplicating the game so they can each take it home is illegal. Get it? We work the same way.
