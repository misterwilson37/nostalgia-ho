About This Manual

This manual was written by Peter Commons and Joe Williams using FrameMaker software from Frame Technologies. The fonts are various styles of Garamond. The graphics for the cover were created in Color MacCheese and Michael’s Draw, and output on a LaserWriter IINT.

Spaceward Ho! Manual (Macintosh, 1990) — from Jake Wilson’s own copy, bought from PC Games Vault (pcgamesvault.com), scanned at 300 dpi; the figures cut from the scans.
