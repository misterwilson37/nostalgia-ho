mssansserif8.ttf, mssansserif8-bold.ttf: Windows 95's MS Sans Serif 8 point (SSERIFE.FON, 11 px), one square per ink pixel, built by tools/extract/winfon.py from the Windows 95 setup disks;
the bold is GDI's (the glyph twice, one pixel apart). The six Turkish letters are from the Turkish Windows 3.11's own fonts. They come with the game's look, like its other Windows art.
