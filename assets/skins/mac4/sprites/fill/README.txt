Made for the Spaceward Ho! web remake, NOT from the original release.

These 31 pictures are stand-ins for the 'mac4' skin. The skin's own original art
always wins: the game draws one of these only where the skin's original has no picture
for something a later ruleset needs (see HOFILL.pic in js/skins/dos/ui.js). None replaces
an original file.

Source: the art package 'nostalgia-ho-art' (Jake and Brand Inspector Sage, a claude.ai
session), integrated October 2026. Each file is a picture from the nearest version that
has it (1.2, 2.0.1, 3.0.1, 4.0.5, then 5.0.5), re-filtered to this skin's look (invert,
outline, dither, palette...). The file name says where it comes from:
<version>-<picture>.png (mac4-p2263 is 4.0.5's p2263). Regenerate or check with
tools/skins/fill_art.py (--check). Overview: docs/missing-assets.md, docs/forward-fill/.
